# Gaze Link

Gaze Link 是一款 Android 眼动辅助沟通应用，用于低成本解决渐冻症ALS或身体失能患者的日常沟通。使用者可以通过前置摄像头注视屏幕选项，也可以触摸操作；应用提供常用表达、中文拼音和逐字母输入、文字编辑与系统语音朗读。照护者可以协助校准、调整操作方式和查看使用质量。

眼动功能用于辅助沟通，不用于疾病诊断。摄像头、眼部光线、佩戴眼镜、姿势和设备摆放都会影响识别；重要表达及自动生成的建议应由使用者或照护者确认。

## 当前版本

- 应用版本：2.10（versionCode 12）
- Android：8.0（API 26）及以上，targetSdk 34
- APK 架构：`arm64-v8a`、`armeabi-v7a`、`x86_64`
- 应用优先横屏；眼动操作需要可用的前置摄像头和相机权限。触摸操作可在眼动不可用时继续使用。

本仓库提供源码和文档，不提交已编译 APK。请按下方步骤在本机生成安装包。

## 功能

- **眼动选择：** 使用前置摄像头识别视线并通过停留选择界面项目；支持双眼、左眼或右眼方案及校准。
- **触摸操作：** 相机不可用或未授权时，仍可通过触摸使用沟通功能。
- **常用表达：** 按日常沟通场景组织短语；支持本机编辑和排序。
- **文字输入：** 支持中文拼音首字母组句、本地拼音选词、常用词句和逐字母输入，可编辑原文。
- **语音朗读：** 使用 Android 系统 TTS，可调整语速；中文朗读需要设备安装并启用中文语音引擎或语音包。
- **可选表达建议：** 用户主动请求后，可通过构建时配置的模型服务生成候选；结果由使用者确认后再采用。
- **照护工具：** 可调停留确认时间、练习可选眼控动作、设置嘴型确认、进行独立方向测试并导出本次诊断报告。

完整操作步骤见[使用说明书](docs/Gaze_Link使用说明书.md)，版本兼容性与测试范围见[2.10 适配与验收记录](docs/Gaze-Link-2.10多机型适配与验收.md)。

## 构建

### 环境

- Android Studio 或兼容的 Gradle 命令行环境
- JDK 17
- Android SDK Platform 34、Android Build Tools 和 NDK/CMake（用于项目原生组件）

### 配置与生成 APK

Windows PowerShell：

```powershell
Copy-Item gradle.properties.example gradle.properties
# 需要在线表达建议时，在本机的 gradle.properties 中设置模型服务参数。
# 不要把 gradle.properties、API 密钥或签名文件提交到 Git。
.\gradlew.bat :app:assembleDebug
```

安装包生成于 `app/build/outputs/apk/debug/`。Android Studio 打开仓库根目录后，也可以使用 Gradle 面板运行 `:app:assembleDebug`。

离线短语、文字输入和系统朗读不依赖模型服务。在线表达建议需要网络及服务配置；服务不可用时仍可使用本地输入和朗读。

> **凭据安全：** Android APK 中的客户端密钥可被提取。仓库忽略了本机 `gradle.properties`，但把密钥写进构建配置仍会将它嵌入 APK。不要在公开发行包中使用个人或生产密钥；正式分发应由受控后端代理模型请求。若某个密钥曾经放入已分享的 APK，请在服务提供方处撤销并轮换。

## 项目结构

```text
app/                         Android 应用、界面、眼动与沟通功能
opencv/                      OpenCV Android 模块及原生组件
gradle/                      Gradle Wrapper 配置
gradle.properties.example    不含密钥的本地构建配置示例
docs/                        使用说明书和 2.10 适配验收记录
```

## 验证范围

2.10 验收记录包含单元测试、Lint 和 Android 15/API 35 模拟器兼容性检查。记录未覆盖各品牌真机验收；摄像头、眼动效果、中文 TTS 和持续运行表现仍需在目标设备上测试。眼动识别质量数据仅供了解单次运行情况，不代表临床评估或医疗准确率。

## 隐私

眼动识别在设备端利用摄像头运行。可选的在线表达建议只在使用者主动请求时发送当前文本及可选对话背景到所配置的模型服务。使用者或照护者主动导出的诊断报告可能包含设备与运行信息；分享前请检查内容和接收对象。
