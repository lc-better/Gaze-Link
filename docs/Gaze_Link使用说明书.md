## 1. 应用简介

Gaze Link 是一款 Android 眼动辅助沟通应用。使用者可以通过前置摄像头识别视线，再以眼动或触摸选择屏幕选项，使用常用短语、拼音或首字母输入、编辑文字，并让手机朗读内容。照护者可以协助校准、调整操作速度、编辑常用表达和查看使用质量。

眼动用于辅助沟通，不用于诊断或监测疾病。医疗、疼痛及其他重要需求应由照护者确认；自动生成的句子也应先确认意思再采用。

## 2. 使用条件与摆放建议

- 需要 Android 8.0（API 26）或更新版本。交付安装包包含 `arm64-v8a`、`armeabi-v7a` 和 `x86_64` 架构。
- 眼动操作需要可用的前置摄像头和相机权限。若没有前置摄像头或拒绝权限，仍可触摸屏幕操作，但不能使用眼动控制。
- 应用以横屏为主要使用方式。建议将手机或平板固定在支架上，屏幕朝向使用者，距离约 30–50 厘米；让脸部和双眼清晰可见，保持均匀光线，避免强背光和明显反光。
- 中文朗读由手机系统的文字转语音（TTS）引擎完成。若系统未启用中文语音或未安装中文语音包，需要先在手机的“文字转语音”设置中启用并安装。
- 常用表达、拼音词库、逐字母输入和已保存的校准不依赖网络。联网表达建议只有在安装版本已配置模型服务、设备可联网并由使用者主动请求时才可用。

## 3. 安装与首次启动

1. 下载本页顶部的 2.10 APK，在 Android 设备上打开安装。若系统询问是否允许从当前来源安装应用，请按设备提示授权。
2. 首次启动时按引导完成设备摆放和功能熟悉。引导可跳过，也可从顶部“帮助”再次打开。
3. 眼动需要相机权限。首次启动时允许相机访问；若拒绝，仍可通过屏幕按钮使用应用。之后可在 Android 的应用权限设置中开启相机，再回到应用使用眼动。
4. 建议第一次先用触摸熟悉页面，然后在“眼动设置”中完成当前识别方案的校准。

## 4. 首页与基本操作

顶部导航可以横向滚动，常用入口包括“首页”“常用表达”“文字输入”“眼动设置”“照护设置”“暂停”和“帮助”。屏幕中央显示当前页面和选项；左、右两侧的大按钮也可直接触摸。

眼动菜单的基本规则如下：

| 操作 | 结果 |
| --- | --- |
| 看左侧并保持 | 选择当前高亮选项；屏幕进度条填满后确认 |
| 看右侧并保持 | 移到下一项 |
| 看回中间 | 休息并准备下一次操作，不会选择菜单项 |
| 触摸左侧或右侧按钮 | 分别执行选择或切换，与眼动操作相同 |

默认停留确认时间为 0.8 秒。每次操作后先看回中间，等视线稳定后再选择下一项。容易误选时，可由照护者将确认时间调慢。页面中的“导航 / 朗读控制”可返回上一级、切换页面、重播或停止朗读，也可暂停眼动。

选择顶部“暂停”后，眼动表达会暂停，朗读会停止。休息后选择“继续”恢复；恢复时先看回中间。

## 5. 校准眼动

首次使用眼动、改变识别方案或发现选择不稳定时，请重新校准。校准与验证通过后才会保存新结果；未通过时原校准会保留。

1. 进入“照护设置”→“识别方案 / 有效眼睛”，选择方案，然后选择“校准当前方案”。
2. 将设备固定在舒适位置，脸朝向屏幕，头部尽量保持不动。校准期间按语音和屏幕提示只移动眼睛看目标。
3. 按提示看中间、左侧和右侧目标。应用会自动采集画面并使用新画面验证；通过后会提示校准已保存。
4. 若失败，调整距离、光线和设备角度后重试。采集期间保持双眼（或所选的那只眼睛）清晰可见。

可选识别方案：

- **虹膜特征：** 双眼、使用者左眼或使用者右眼。若一只眼睛难以稳定使用，可尝试单眼方案。
- **原版图像模板：** 使用双眼。

每种方案和有效眼睛组合分别校准。切换方案后，先为当前方案校准并进行独立方向测试。校准与安装设备、屏幕方向和分辨率相关；更换手机、旋转设备、折叠或展开屏幕、改变显示分辨率后，可能需要重新校准。

## 6. 常用表达

打开“常用表达”，先选分类，再选要表达的短语。当前内置分类为“常用”“饮食”“照护”“不适”和“心情”。短语保存在本机，离线可用；选中后会由手机朗读。

在“撤销 / 重播 / 停止”中可以重播刚才内容、停止朗读或撤销当前选中的短语。撤销只能改变应用显示的当前表达，不能收回已经播放的声音。

照护者可以从“照护设置”→“编辑 / 排序常用短语”修改分类内容。每行输入一句，行顺序就是页面展示顺序。常用短语适合快速表达；需要组织新的内容时使用“文字输入”。

## 7. 文字输入

“文字输入”提供四种方式。选择得到的文字会先加入原文，不会因选中词语而自动朗读；使用者可继续输入、编辑或朗读。

### 首字母组句

按屏幕上的字母分组选择每个汉字的拼音首字母。完成输入后选择“生成候选”，再查看并确认合适的句子。可返回修改首字母、删除末个字母或清空重来。词库命中时可离线生成候选；若需要联网补充，必须主动选择联网生成，并在采用前核对句意。

### 拼音选词

每次输入拼音的一个字母时，选择其所属字母组：`A–F`、`G–M`、`N–T`、`U–Z`。完成拼音后查看本地候选，选择合适的词语加入原文。该词库不是完整输入法，找不到的姓名、地名和常用词可由照护者添加到个人词库。

### 常用词句

从与“常用表达”相同的分类中选择词句，添加到当前原文。适合把已有短语与其他输入方式组合使用。

### 逐字母输入

按字母组逐步选择英文字母，再加入原文；适合输入英文或缩写。

### 编辑原文与表达建议

照护者可触摸“照护者编辑”直接修改原文，也可编辑可选的对话背景。选择“编辑 / 朗读操作”可撤销上次编辑、清空原文、请求表达建议、重播或停止朗读。

表达建议是可选的联网功能，需要当前安装版本已配置模型服务。只有主动请求建议时，应用才会将当前原文或首字母及填写的对话背景发送给已配置的模型服务。网络或服务不可用时，仍可使用本地输入并朗读原文。建议结果不会自动替换原文或自动朗读；请先确认意思，再选择采用、采用并朗读或放弃。

## 8. 照护者设置与可选控制

从“照护设置”进入以下项目：

- **识别方案 / 有效眼睛：** 选择虹膜特征或原版图像模板，以及双眼或单眼方案；切换后需重新校准当前方案。
- **停留速度：** 可选较快 0.6 秒、标准 0.8 秒、较慢 1.2 秒。若容易误选，尝试较慢；若停留确认过慢，可尝试较快。
- **眨眼练习 / 设置：** 眨眼控制默认关闭。建议先在“眨眼练习”中观察识别结果，再决定是否启用。启用后，使用者左眼闭合用于确认、右眼闭合用于返回、双眼长闭用于取消。练习页面只记录手势，不会触发菜单命令。
- **嘴型确认 / 设置：** 默认关闭。启用后需完成“闭嘴准备→张嘴保持→闭嘴”的动作，并且视线稳定看向左右操作区。说话、哈欠或短暂张嘴不应直接触发确认。建议确认摄像头能清楚看到嘴部后再试用。
- **朗读语速：** 慢、标准、快三档，选择后会试听。
- **手机语音设置：** 打开系统文字转语音设置，用于启用语音引擎或安装语音包。
- **编辑 / 排序常用短语：** 修改短语和显示顺序。
- **个人拼音词库：** 每行输入“拼音空格文字”，例如 `xiaoming 小明`；保存后可用于拼音选词和首字母候选。
- **查看使用质量：** 查看当前校准和运行数据，或进入独立方向测试。

建议初次使用保持眨眼和嘴型控制关闭，先熟悉基本眼动或触摸操作。若可选控制产生误触，立即关闭并改用眼动停留或触摸。

## 9. 独立方向测试与诊断导出

进入“照护设置”→“查看使用质量”→“独立方向测试”，按提示看中间、左侧或右侧目标。测试共 25 个目标，约需 90 秒；测试不会修改校准，也不会朗读常用短语。测试期间请保持与校准相同的设备位置，并由照护者确认使用者确实跟随目标。错误或无法分辨的目标会记录在结果中。

测试完成后可查看或导出结果。使用“导出本次诊断”会打开 Android 分享面板；报告包含设备型号、Android 版本、屏幕信息、校准状态和本次运行数据。分享前请检查接收对象和报告内容。

运行帧率、处理耗时和有效方向识别比例用于了解本次运行情况，不等同于临床评估或眼动准确率。独立测试结果也不保证长期使用效果。

## 10. 隐私与使用边界

眼动和相机画面用于本机识别操作；表达建议请求发送的是输入文字、首字母及可选对话背景，不会把这些信息自动发送到未配置的服务。离线短语、词库、校准和系统朗读可在没有网络时使用。分享诊断报告由使用者或照护者主动发起。

应用识别会受摄像头位置、脸部光线、眼镜反光、头部移动、设备距离和屏幕尺寸影响。请把眼动作为沟通辅助，必要时使用触摸或由照护者协助确认。

## 11. 常见问题

| 问题 | 建议处理 |
| --- | --- |
| 眼动没有反应 | 确认已授权相机、前置摄像头可用、脸部在画面内且光线合适；重新校准当前方案。未校准时可直接触摸表达。 |
| 经常误选或漏选 | 固定设备，减少头部移动和屏幕反光；看回中间再操作；将停留时间调慢，必要时重新校准。 |
| 只想用一只眼睛操作 | 在识别方案中选择对应的单眼模式，为该模式单独校准，再做方向测试。 |
| 没有中文声音 | 在手机“文字转语音”设置中启用 TTS 并安装中文语音包，然后回到应用重新试听。 |
| 没有表达建议 | 该功能需联网且安装版本已配置模型服务。没有配置或请求失败时，可继续用拼音、本地词库、常用短语或逐字母输入。 |
| 更换设备或屏幕尺寸后不准 | 在当前设备、方向和分辨率下重新校准，并重新做独立方向测试。 |
| 相机权限被拒绝 | 在 Android 应用权限中开启相机。开启前仍可触摸使用；返回应用后可重新尝试眼动操作。 |

## 12. 版本与适配说明

此说明书对应 Gaze Link 2.10。交付包最低支持 Android 8.0，包含 ARM64、ARM32 和 x86_64 架构。该版本完成了 125 项单元测试，并在 Android 15/API 35 的兼容性模拟器中完成 26 项检查。**尚未连接 Android 真机进行验收**；相机视角、眼动效果、中文语音包和长时间运行体验可能因设备而异，实际使用前请在目标设备上校准并测试。
