# Gaze Link 2.10 多机型适配与验收

日期：2026-11-04。基于当前工程（包含首次引导浮层）的版本 2.9 修改，版本号 2.10，versionCode 12。

本次完成通用兼容问题修复、构建检查及可获得环境中的运行检查。各品牌相机、眼动准确率、语音包和长时间使用表现，需要在对应真机验收；不能将模拟器或库文件检查表述为“所有机型完美适配”。

## 安装范围

- 安装包：同目录 `Gaze-Link-2.10-multi-device.apk`。Android 8.0（API 26）及以上；targetSdk 34。
- 包含 ARM64、ARM32、x86_64 的完整相机、OpenCV、人脸检测和 MediaPipe 原生库。
- 面向小米 / Redmi、OPPO / 一加、vivo / iQOO、荣耀、三星、Pixel，以及仍能安装 Android APK 的华为系统。品牌名称表示适配目标，不表示已完成该品牌真机测试。
- 应用保持横屏优先。系统强制竖向时，可能以带上下留白的横屏兼容窗口显示；本次额外检查了这种极短窗口的按钮文字与引导。日常眼动沟通仍建议横放手机。
- iPhone 和不兼容 Android APK 的鸿蒙 NEXT / HarmonyOS 5、6 原生系统，需要单独开发客户端，本 APK 无法覆盖。
- 眼控需要可访问的前置相机；缺少前置相机或拒绝权限时显示提示，可继续触摸操作。中文朗读需要手机安装并启用中文 TTS 引擎 / 语音包。

## 本次修改

1. 解除 Mate 60 Pro 的 ARM64 单架构打包限制，逐一检查每个架构实际包含所需原生库。
2. OpenCV 改用官方 4.12.0；CameraX 从 1.1.0-beta01 升至稳定版 1.4.2；MediaPipe 升至 0.10.32；内置 ML Kit 人脸检测升至 16.1.7。ML Kit 使用内置模型，不要求用户先下载 Play Services 模型。
3. 清除没有 Java / Kotlin 调用的旧 TensorFlow Lite Task 音频、文字、视觉依赖和示例 JNI 构建。它们会带入不兼容 16 KB 页的原生库；保留原有模型资源和识别业务代码。
4. 对最终 APK 内全部 ARM64 / x86_64 ELF 的每个 LOAD 段检查 16 KB 对齐及 offset / vaddr 一致性。AGP 8.4 采用压缩并在安装时提取原生库的方式，避免旧打包工具的未压缩库 ZIP 对齐问题。
5. 显式处理状态栏、导航栏、挖孔 / 刘海和键盘安全区。内容与方向提示浮层共享安全边界，避免重复留白；方向提示位置取自真实控件位置。
6. 顶部导航支持横向滚动，避免小屏硬挤七个按钮；侧边按钮根据空间调整文字，对大字体和极短兼容窗口使用紧凑排版；中央阅读区保留滚动。状态 / 语音提示按字体测量行高。首次引导改为可滚动卡片，操作按钮可横向滚动。
7. 监听屏幕变化，横屏翻转 180° 时同步更新 CameraX 分析方向；屏幕几何变化时使旧校准失效。校准中发生变化时退出本次采集，防止混用两种方向的画面。
8. 校准绑定本次安装的本地标识、显示方向和分辨率。本地标识放在不参与备份的目录；换机恢复、折叠屏尺寸变化或分辨率调整后需要重新校准。旧校准文件保留，但不能跳过新验证直接启用。首次引导浮层显示时暂停眼动命令。
9. 诊断导出增加品牌、型号、Android 版本、支持架构、屏幕方向 / 分辨率及内存页大小，便于收集真机问题。

## 验证依据

构建命令：

```text
gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:lintDebug :app:assembleDebugAndroidTest --no-daemon "-Dorg.gradle.jvmargs=-Xmx1024m" --console=plain --max-workers=2
```

单元测试覆盖原有输入、眨眼、嘴型、YUV stride / crop、校准和请求控制，以及新增的换机、旋转、折叠和分辨率变化校准隔离测试。

单元测试 125 项全部通过，Lint 错误 0、警告 129。APK 签名与旧版一致，覆盖安装校验、ZIP 对齐及 64 位 ELF 16 KB 对齐校验通过。

最终构建检查中，125 项单元测试通过，Lint 有 0 个错误并保留 29 个警告；Android 15 / API 35 模拟器的 26 项兼容检查全部通过。未执行真机验收。

模拟器使用 Android 15 / API 35 的专用 16 KB x86_64 系统镜像。最终安装包通过 12 种屏幕 / 字体 / 导航配置的 24 项布局检查，以及原生视觉库和前摄分析链路的 2 项检查，共 26 项全部通过；被测 APK 与交付 APK 的 SHA-256 一致。检查 OpenCV 原生运算、MediaPipe 加载实际内置模型并对合成图执行推理，以及不同窗口 / 字体下的控件边界和首次引导滚动。合成图推理仅证明运行链路能执行，不能用于评估人脸或眼动准确率。这些合成图测试仅证明运行链路可以执行，不能用于评估真实设备的人脸或眼动准确率，也不代表各品牌真机验收。

另有前置模拟相机取帧、RGB 转换和人脸分析集成测试。扩展屏幕检查包含手势 / 三键导航、模拟挖孔、反向横屏和系统强制竖向的兼容窗口。检查会等待旋转完成，并保存实际截图像素尺寸，避免将布局过渡状态当作最终结果。一次早期模拟器运行受到系统镜像崩溃影响；随后对最终包重新执行检查，最终测试范围以本记录列出的结果为准。本次不将中文语音效果、系统 TTS 的 16 KB 兼容性或各品牌真实摄像头识别率记为通过。

## 升级与真机验收

升级后请在当前手机、横屏方向与实际支架摆位下重新校准。视觉库升级可能改变数值结果，不能复用旧版本的验证结论。使用原有签名和递增版本号，可覆盖安装旧版；请先保留现有 APK 以便对照。

每个需要正式支持的型号，至少完成以下项目并记录系统版本：

| 项目 | 验收内容 | 当前真机状态 |
| --- | --- | --- |
| 安装与启动 | 覆盖安装、冷启动、相机授权 / 拒绝 / 再授权、后台恢复 | 待实机 |
| 显示 | 两种横屏方向、挖孔 / 刘海、手势 / 三键导航、大字体、编辑时软键盘 | 待实机 |
| 相机 | 前摄可用、画面方向正确、预览镜像与实际识别方向正确 | 待实机 |
| 校准与眼控 | 原版 / 虹膜方案、双眼 / 单眼、左右选择、停留、暂停 / 恢复 | 待实机 |
| 辅助控制 | 眨眼、嘴型默认关闭；启用后验证误触与取消路径 | 待实机 |
| 换机与折叠 | 数据恢复后必须重新校准；翻转 / 展开后校准状态正确 | 待实机 |
| 沟通与语音 | 离线短语 / 输入、中文 TTS、联网候选、失败时返回本地操作 | 待实机 |
| 稳定性 | 连续使用 30 分钟，记录帧率、耗时、温升、丢失跟踪及误选择 | 待实机 |

相机焦距、前摄位置、屏幕物理尺寸、使用者姿势和 TTS 引擎存在设备差异；应保留每台手机的独立校准与方向测试报告。
